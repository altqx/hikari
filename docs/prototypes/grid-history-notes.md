## Run and review

Plain click selects a Line. Ctrl-click toggles it; Shift-click selects a displayed range; Ctrl+Shift adds the range. Clicking a row returns keyboard focus to the Grid container. Arrow/Page/Home/End navigate displayed order; Ctrl changes current without replacing selection; Shift extends from the anchor; Space toggles current. A hidden anchor uses the explicitly selected proposed fallback. Empty results preserve identities. Use Reveal current/selected to recover visibility.

The scope selector distinguishes selected displayed Lines, selected including hidden, all displayed, whole Document and current only. Counts and stable IDs appear before every row mutation. Insertion/paste use their explicitly named current-Line anchor rather than implicitly consuming a batch selection. Display sort changes only the projection; the reviewed Sort command permutes the scoped source-order slots.

Each guided scenario resets the fixture. A modal review repeats the next walkthrough action in its footer. Free play is available; every command still produces a review rather than immediately changing content.

1. **Hidden selection & range:** select A1/A3, hide them, then compare displayed-only deletion with include-hidden deletion. The latter reveals its group consequence because A3 belongs to G1. Cancel preserves content and selection. Free play: Shift+End after hiding the anchor; compare the two named fallback alternatives.
2. **Group-breaking command:** duplicate A2 within G1. Apply without an annotation decision leaves the document unchanged. Explicitly remove affected group annotations or cancel. Apply the reviewed choice, then Undo: original identities, description/membership and current A2 return. Separately try creation from a contiguous run, collapse/expand, description rename and explicit ungroup.
3. **History branch & saved point:** duplicate A1; simulate a saved snapshot; Undo; preview a new insertion. The review names the redo entry that will disappear. After applying, the saved identity remains known but outside retained history; a new entry at the old list index does not become “saved.” Rewind similarly previews permanent removal; ordinary Go to/Undo/Redo preserves future entries.
4. **Draft collision & targeting:** stage A1 text, preview deletion, then explicitly commit the affected draft and rebuild the review. The rebuilt deletion is still unapplied. Cancel it; switch editing to Song; pin History to Harbor; inspect protected Reference in the Grid. Grid focus does not retarget History or turn Reference into a writable Document.

Typing in the Editor immediately retains a memory draft; Stage text draft also exposes that operation explicitly. This retention is the proposed study behavior, not an answer to the still-open navigation/reconciliation policy. Committed Grid text remains unchanged until reviewed commit. The live-state panel reports each Document's current/selected/anchor/marked IDs, source/display order, filter-hidden set, collapsed groups, histories and pending draft IDs.

## Deliberately proposed mechanics

- Scope is captured as Line IDs with Document/revision/history identity. Changing the editing tab never retargets a prepared command. An inline review becomes stale after another recorded operation and cannot apply until rebuilt. View selection alone does not change the captured scope.
- Shift uses displayed order. If the anchor is hidden, compare destination fallback against visible-current fallback. The original anchor remains retained. Deleted current/anchor/marked identities become empty; they do not jump to an unrelated occupant. Undo restores the recorded context. These finer rules still need human reaction.
- Group-breaking commands are blocked until an explicit choice. The available demonstration choice removes affected group annotations while retaining surviving description comments/member Lines. It does not silently reorder, extend membership or invent nesting. A newly created group starts collapsed. Other accepted semantics may replace these proposals.
- Duplicate/paste create new IDs; a split retains the original on its first fragment. The representative join retains the first ID even when last properties are chosen. Word/wrap split distributes time evenly and copies translation unchanged; these are visible fixture choices, not proven legacy behavior.
- One-row paste-special may repeat across targets; otherwise counts must match. Mapping is in Document order and only checked, available fields change. Bulk commands are one history entry in this study. Full legacy clipboard mismatch behavior remains to characterize.
- Filters preserve selected IDs. Add unions hidden sets; predicate inversion and current-set inversion are separate actions. The predicate follows the observed style/selection short-circuits and Unconfirmed/untranslated combination for the represented flags. Collapse is another visibility reason. Filter actions appear in proposed view history without changing semantic saved-content equality; that dirty/restore policy is not accepted legacy parity.
- Draft conflicts default to keeping drafts and withholding the command. Explicit discard touches only named affected drafts. Explicit commit records them, then rebuilds the command for another review. History/save requires resolving drafts separately or explicit discard; no silent automatic policy is assumed. This simplified text-only model conservatively reconciles structural dependencies; complete field-overlap rebasing remains future work.
- The simulated saved identity compares the exact serialized **fixture model content**, not actual encoded subtitle bytes. It stays separate from mutable history position. New commands/rewind preview removed future entries; actual save and restart persistence are absent. No typing coalescing or pruning approximation is presented as a pass.

## Root browser observations

At the default 1280-pixel viewport, the hidden-selection walkthrough produced an empty displayed-only delete scope and exactly A1/A3 (two hidden Lines) for include-hidden. A group-breaking duplicate without the explicit annotation-removal choice was rejected with a visible explanation. A new edit after Undo previewed one removed redo entry; after apply, current A-H2 and saved A-H1 remained distinct and dirty. Draft collision explicitly committed A1 then rebuilt deletion at revision1; cancelling the rebuilt plan retained that commit. With Song as Editing target, History stayed pinned to Harbor while Grid inspected the protected reference, whose Apply button was disabled. A modal and B inline review were visually reviewed. These bounded browser checks do not certify native accessibility, all commands or legacy group semantics.

The durable saved-content identity demonstrated by the branch scenario is the explicitly unapproved C43-save-identity proposal in the transaction specification. Retaining the legacy 500-state capacity does not itself approve that changed dirty-state behavior.

Grid filter changes in this study deliberately create a proposed view-history entry and advance its synthetic dirty identity even when source rows are unchanged. This is an alternative for review, not a settled document-content or legacy save rule. Apply remains clickable for unresolved draft/group choices so it can explain the rejection; the model rejects before mutation. Protected Apply is disabled.
