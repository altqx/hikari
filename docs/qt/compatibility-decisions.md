# Approved compatibility departures

The [compatibility policy](compatibility.md) requires approval of named outcomes. The live review on **2026-09-27** approved the document, timing, transaction, lifecycle and short-hotkey-file outcomes below. Their corrected behavior becomes default when implemented and validated. No row is implemented or measured here; approval is not a fixture pass.

The suffixes refine the broader candidate rows so approval cannot be mistaken for acceptance of unrelated changes in the same row. Evidence remains pinned in the [candidate ledger](proposals/compatibility-policy.md), [document-model proposal](proposals/document-model.md) and [time-semantics proposal](proposals/time-semantics.md).
