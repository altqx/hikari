# Backend values, capabilities and resource ownership

**Accepted contract, 2026-09-27.** In the live review, altqx answered **“#62 yes”** to [Define backend interfaces, capabilities and resource ownership](https://github.com/altqx/hikari/issues/62), accepting the value/capability/ownership contract and **qualifying an isolated FFMS2 media worker first**, with Qt general playback in the application process. [ADR 0016](../adr/0016-backend-values-and-isolated-ffms2.md) records this direction. The [reviewed proposal](https://github.com/altqx/hikari/blob/752588a7f8146f4bd94bf9b185524875d8672af9/docs/qt/proposals/backend-interfaces.md) is its historical source; acceptance is not a native, packaging or performance pass.

This refines the [Hikari-owned architecture](architecture.md), [media](media.md), [typed time](time-semantics.md) and [fonts](fonts.md) contracts. The [edit-transaction](proposals/edit-transactions.md) and [application-lifecycle](proposals/application-lifecycle.md) proposals remain unaccepted: their draft, undo, save/close and recovery choices do not follow from this decision. Concrete C++ classes, IPC encoding, measured queue capacities and service APIs remain implementation work within these responsibilities.

## Shared boundary

Application ports exchange standard C++ value records, typed times, optional values and explicit results. Core depends on subtitle/time values and algorithms, not backend services. Qt and native handles stay inside adapters; UI models convert values into Qt properties. QML delegates submit application commands rather than calling native libraries.

Asynchronous requests capture RequestId, relevant Document identity/lifetime/content revision, resource/source generation, adapter-instance generation and the configuration generations actually used. Track identity belongs to a source generation; indexed frame identity belongs to an indexed timeline. General-player timestamps cannot manufacture indexed identities. Device identity is scoped to its backend/enumeration, not its display name. Descriptors retain requested location, resolved identity, provenance and confidence; basename/mtime alone cannot certify source equality. Replacement or restart advances the appropriate generations without changing authored Document times or borrowing another Document's Audio.

Capabilities separate advertised support from verified runtime/package qualification and report prerequisites, limits and unavailable reasons. Exact indexed seek, time seek, tracks, chapters, subtitle suppression, CPU frames, native textures and output-quiescence evidence are distinct. Results distinguish MissingDependency, Unsupported, UnavailableResource, InvalidInput, Stale, Cancelled, Superseded, Busy, DeviceLost and BackendFailure; EOF is normal. Diagnostics carry stable codes, bounded backend detail and safe contextual values; the application localizes them.

An immutable BufferLease retains storage until every consumer releases it, with byte count, layout, generation and owning release route. Check dimensions, strides and ranges before publication. Borrowed FFMS2/libass output cannot outlive its native validity. Cross-process transfer uses versioned descriptors and owned copies or validated shared-memory leases, never C++ pointers, Qt objects or library handles. Shared memory requires release acknowledgements and crash cleanup; it is not automatically zero-copy.

## Native ports and owners

These names describe responsibilities and outcomes, not a frozen ABI.

| Port | Contract |
| --- | --- |
| IndexedSource | Open/index returns tracks, progress, timeline and provenance; frame requests return the exact indexed identity or EOF/error; source-sample ranges return PCM. One owner serializes native calls. Requests capture track/decoder/seek settings and use the accepted FFMS_SEEK_NORMAL direction. Frames retain rational PTS/origin, optional duration, planes/strides/format, geometry/SAR/crop and separate range/matrix/primaries/transfer metadata. |
| GeneralPlayer | Open, track selection, time seek and transport return actual delivered timestamps, buffering/state and clock estimates. Chapters may use a companion metadata port. Time-seek results distinguish requested/delivered position, accuracy and unknown duration. Position notifications alone cannot acknowledge a frame. The active player owns its audio and A/V scheduling; editor PortAudio does not receive its audio. |
| SubtitleRenderer | Prepare an explicit Document/font/configuration snapshot and render at a time/geometry into ordered masks or owned pixels, change regions and font diagnostics. The application authorizes committed or draft-preview identity/text role; rendering cannot commit a draft. Its owner serializes libass, copies transient output and retains font/attachment leases until context destruction. |
| FontService | Enumerate/resolve names, style/glyph requirements and environment; collect a snapshot/scope into verified bytes/hash, collection face, available instance coordinates, fallback/simulation and completeness diagnostics. Preserve authored names. Picker candidates and Qt samples are not renderer proof. Document environments stay separate; duplicate/system precedence needs characterized evidence. |
| Presenter | Accept immutable frame/overlay leases and a presentation transform/generation; report accepted, superseded or error and the actual completion stage. The Qt render-thread owner creates/uploads/destroys graphics resources without waiting for decoding. Visual tools share the forward/inverse coordinate transform while retaining separate command geometry. New window/device generations reject stale uploads. |

Owned decode completion, scene consumption, GPU completion and physical display observation are different evidence. Retain the CPU-BGRA/libass reference and compare frame/color/alpha metadata with QSG presentation. Barcode identity is insufficient. Native textures are optional later work requiring device compatibility, synchronization and release. Empty/disappearing subtitle overlays invalidate old pixels even while paused.

Font hooks expose owned provider bytes and opened-face identity; cache-local UIDs are not persistent identity. Font, attachment or provider changes advance environment generations, invalidate reports and recreate affected contexts while existing consumers retain their leases. Unresolved fallback or instance identity stays incomplete. Optional CSRI/VSFilter needs separate agreement evidence.

## Audio, analysis and bounded work

AudioDecode returns immutable PCM with source rate, channel layout, format, sample range/origin and processing identity. Output preparation records device-format negotiation and resampling/channel/delay mappings. Source sample frames, device frames and monotonic time remain distinct. PortAudio output reports device lifecycle and clock estimates with domain, epoch and uncertainty.

The real-time callback consumes ready buffers, fills remaining output with silence and records bounded lock-free status. It performs no allocation/reclamation, disk I/O, logging, Qt dispatch or decoding; the control owner retires leases and drains telemetry. Seek, underrun, device replacement and suspend invalidate stale estimates. Preserve half-open source audition ranges; resampling tails, variable/reverse scrub, fades and device-follow/reopen policies retain their existing unresolved status.

Analysis requests identify source range, resolution/channel policy and FFT/window/hop where relevant. Immutable peak/magnitude results expose exact coverage and generation. QSG waveform geometry and cached spectrum tiles remain the direction; recoloring reuses magnitudes and cursor/selection redraw does not rerun analysis. Cache keys include verified source identity, track, decoder build and format/rate/channel/delay/analysis settings. Partial results advertise coverage, never completion; eviction respects leases. Activation/cleanup requires current application authorization. The precise file-permit and lifecycle APIs remain pending.

Every owner bounds queue length and bytes. Submission returns Accepted(RequestId) or an explicit unavailable/busy result. Latest-view work may be superseded with a terminal outcome; exact frame requests cannot silently change identity. Playback may drop late frames under the transport policy. Coalesce progress, retain terminal outcomes and count truncated diagnostics. Queue sizes and CPU/GPU/disk budgets require [measurement](performance.md).

The application state owner validates identities, dependencies and target permissions before publishing completion. Following/pinned tools do not retarget pending results; protected references remain non-mutable. Workers cannot acquire undo/history authority. Cancellation is cooperative; each request resolves once, while release may finish later. Cancelling an observer cannot free storage still used by a decoder, audio callback or GPU.

## Handoff, shutdown and platform integration

Mode switching stops old admission, requests stop/flush, invalidates old transport generations/clock estimates, obtains actual output-quiescence evidence, resolves destination identity/time and acknowledges its indexed frame or honestly described general-player result before authorizing new audio/clock ownership. Logical Stopped, callback cessation, backend-buffer release and measured device tail stay separate; timeout is not drain evidence.

Shutdown revokes work, cancels/drains tasks, stops transport and releases leases through their owners. Keep owners alive through release; do not kill an in-process native worker. Helper loss closes its generation and pending requests; replacements reject old replies. Recovery/reopen choices remain user-visible policies, not automatic macro or operation reruns. Ignoring late callbacks does not authorize stale file/cache writes.

Platform ports expose GUI-affine dialogs/clipboard/external-open with initiating identity, typed outcomes and focus-return targets; explicit user-data/config/cache/recovery versus portable paths; checked file operations and optional handler integration; process argument vectors/package identity and separate start/progress/completion; and update-check outcomes by platform/package/channel. Preserve synchronous Lua-facing semantics without blocking the GUI on a helper that needs a GUI reply. No new Lua API or compatibility departure is approved.

Follow [distribution](distribution.md): preserve disabled checks/reminders, open validated release pages only by user action, and do not automatically download/install/restart. User data survives uninstall; portable integration is explicit. Diagnostics export is deliberate and excludes secrets/unrequested content. Composition selects audited built-in adapters and supported optional Windows DirectShow/CSRI adapters, without automatic architecture fallback or a general extension SDK. Manifests enumerate plugins, helpers and dynamic libraries; missing/conflicting dependencies must fail qualification.

## Isolated FFMS2 direction and outstanding evidence

Qualify FFMS2 in an isolated media helper first, with Qt general playback in the application process. This is independent of Lua's helper lifetime. The alternative common compatible FFmpeg closure is not the initial direction; switching requires an explicit revised architecture decision. Isolation adds transfer/lease, startup, memory, recovery and packaging obligations rather than proving them solved.

The [Windows continuation](https://github.com/altqx/hikari/blob/4012f2ecf6cbf2ba267753c8c0f8417d2ca1f33a/HikariSub/prototypes/media-transport/README.md) loaded different hashes of same-named FFmpeg DLLs in separate processes. That supports avoiding unproved coexistence; it establishes neither inevitable failure of every shared build nor a shipping helper ABI. Its seek discrepancies, software presentation and silent PortAudio callbacks do not prove exact general seeks, GPU/libass/color agreement, source-PCM playback or acoustic drain.

Required evidence remains: exact VFR/B-frame/long-GOP requests; tracks/chapters/subtitle suppression; cancellation/late results and helper loss; real PCM/resampling/device loss; clock handoff and output tails; presentation/color/alpha and font leases; concurrent refresh; bounded resource growth; loader origins, license/dependency manifests and clean supported-platform packaging. Follow accepted [build](build.md), [platform](platform-policy.md), [testing](testing.md) and performance gates. Windows feasibility does not qualify Linux. The font experiment's incomplete multilingual replay remains incomplete. This acceptance settles responsibility and the first isolation direction, not native results, pending surface choices or release readiness.
