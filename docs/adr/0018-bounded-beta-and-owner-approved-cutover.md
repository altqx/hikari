# Bound public betas and require owner approval for stable cutover

On 2026-09-27, altqx accepted bounded opt-in betas under applicable workflow, safety and package checks, with incomplete capabilities clearly disclosed and every stable gate retained. The [readiness policy](../qt/proposals/cutover-readiness.md) requires isolated legacy/Qt profiles and independently tested rollback; this allows feedback before full qualification without treating beta use as passed stable evidence.

Qt replaces `main` only after every stable gate passes for a concrete candidate and the owner approves it. Preserve the old line and recovery material; wx then becomes an archive unless a scoped support line is commissioned. Policy acceptance authorizes no release, branch operation or Windows 10 retirement, and rollback never silently downgrades Documents.
