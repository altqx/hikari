Privacy

Use prompt caching

The provider keeps the start of a conversation for a few minutes, so the next turn costs less. Nothing is stored on this computer.

What is sentWhat is sent to providers{{i:open-link}}

Requests go only to the providers you add and to Brave Search. The AI component runs in a sandbox and reaches the network only through HikariSub.

What is sent gains a Web search entry
With web search on: the searches the agent writes and the addresses of pages it opens go to the provider, or to your search service for providers without their own. Results are kept only for that turn.
