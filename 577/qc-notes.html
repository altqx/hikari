Which line a note marks

The line on screen at the note’s time. If several are, the one that starts closest to it. If none is, the line that starts closest, up to 15 seconds away, as in Note Browser. Comment lines are skipped. The match is worked out again when times change, so a note stays with the moment it describes.

Where it opens

Subtitles › QC notes…, placed by DK2’s rule. Also View › Panels › QC notes. No built-in layout holds it.

Keyboard

Next QC note and Previous QC note work from anywhere and have no default keys. In the list: ↑ ↓ move, Enter goes to the note, Space marks it done, Esc goes back to the Grid.

Screen readers

A note reads “3:24, TLC, line 57, yabai should be…, not done”. A Grid row with notes adds “2 QC notes”, as it adds “bookmarked”.
