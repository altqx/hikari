Where the options live recs 5, 7 and 8

5 · In the .ass, as [Script Info] keys. Only rows that differ from the default are written, numbered in the order of the styles, and rewritten together on every change.

[Script Info] ScriptType: v4.00+ PlayResX: 1920 PlayResY: 1080 Hikari srv3 1: Karaoke-Romaji,glow+hard,karaoke,#FFE45C,#7A2BD8, Hikari srv3 2: Sign-Top,soft,-,,, [V4+ Styles] Format: Name, Fontname, Fontsize, …
Fieldsstyle, shadow types (glow, soft, hard, bevel joined with +, or none), karaoke or -, then the current-word text, outline and shadow colours, each #RRGGBB or empty for No colour. Why numberedYTSubConverter reads [Script Info] lines as ^([\w ]+):. A key with the style name in it, such as Hikari srv3 Sign-Top:, makes it refuse the whole file (tested on 1.6.5). Style namescan't contain commas in ASS, so the style can come first. Renaming a styleupdates its key in the same undo step; deleting a style removes it; duplicating copies it.

Why the Export dialog is the recommended home

  • The options do nothing outside srv3 export. In the Style manager they would sit in front of everyone who never exports to YouTube.
  • The export table lists only the styles that the exported lines use, next to the choice that uses them.
  • The Style manager also edits catalogue styles and several styles at once. The options are stored in the file's [Script Info], not in the Style line, so neither case fits.
  • It is one place to build and test, and it can still grow an entry in the Style manager later if people look for it there.
