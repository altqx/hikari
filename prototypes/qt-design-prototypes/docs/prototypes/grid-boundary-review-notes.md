## Walkthrough and recorded outcomes

1. **Hidden interior row:** A/H/B, H hidden, anchor A. Inclusive membership selects A/H/B; displayed-only selects A/B. H stays hidden in both. Apply, inspect the hidden count, Undo or Reset, and compare. Preserve the characterized inclusive rule unless a change is requested; this is not another required vote. Already-retained hidden selection is a separate accepted rule. This fixture fixes current-moving-on-selection and does not decide hidden/deleted-anchor fallback, Ctrl-addition or display-only sorting.
2. **Group boundary — accepted G56-contiguity:** D/A/B form one group; C is ordinary. Duplicate A produces D/A/A-copy/B/C and remains valid. Move A after C previews the broken flag run and rejects without content, selection, dirty-state or history mutation. Offer Cancel or explicit Remove group: it deletes description D and leaves members ungrouped/revealed. The description loss is shown before Apply. Then review Move again; removal does not silently execute it. Undo each operation. This precise valid-edit/reject/remove/retry outcome is accepted. No general structural validator or automatic repair is implemented; no import-rejection or Lua contract change follows.
3. **Join — accepted J56-selected-only-join:** default A/B/X/C selects A/B/C. Both alternatives combine only A/B/C text and spanning times into A. The source-derived interval deletes B/X/C; the accepted selected-only outcome deletes B/C and preserves X. The source simulation requires acknowledging X's deletion. Switch to **two selected · control case**: A/X/B selects A/B, and **both delete B only and preserve X**. The source deletes from the *second* selected row through the last; a hidden or unselected row between the first and second selections is outside that interval. Only the deletion-set change is approved. Existing contributors, separator, roles, timing, property source, survivor and command eligibility remain unchanged; this is not approval of unrelated Join, translation or group fixes.

## Checks

Both inline scripts parsed. Nine bounded model result records covered the two range memberships, valid duplication, unchanged content/selection/revision/Undo on rejection, separate removal/move/Undo, and both Join modes with two versus three selected Lines. The two-selected modes both retained X; only the three-selected source interval removed it. These were direct observations of the fixture module, not an added formal test suite.

The three-selected source Join removed X; Undo and selected-only Join retained X with its original text. The two-selected source preview correctly listed only B as deleted. Escape closed its review without applying. Browser error log inspection returned no errors.
