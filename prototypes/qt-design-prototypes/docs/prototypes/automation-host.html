Walkthroughs and precise review questions
Walkthrough buttons reset only this sample. Progress advances by button, with no real elapsed-time guarantee. Switching arrangement preserves all sample state.
  1. Placement: a manager task window with independent task strip, or a persistent manager tool beside the workspace?
  2. Recovery: does Cancel → “still waiting” → explicit Force stop → explicit Restart explain the consequences clearly? The grace period and automatic escalation policy remain undecided.
  3. Concurrency and edits: accept one active macro application-wide and a captured target reserved until completion, or require another interaction? Atomic staged apply / undo semantics still need their named C06–C08 decisions.
Script-created options remain task dialogs in both arrangements. This study does not approve native compatibility, default-button fixes, timing deadlines, callback semantics or helper lifetime.
