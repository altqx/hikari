# T5: the legacy drawing tool and its shape presets (clip_capture.cpp built
# as legacy_drawing_capture). The rewrite's replay
# (hikari_application_visual_drawing_tests) sets the same view up from
# "client", "frame" and "zoomat" and checks it gives the "video" and "zoom"
# lines the legacy probe runs with.
#
# Script 1920x1080 on a 640x360 video: 3 script units a pixel. The Lines
# show from 1000 to 2000 ms; the video is at 1500 ms unless "time" says.

# --- Free drawing (the shape list on "Choose") ------------------------------
