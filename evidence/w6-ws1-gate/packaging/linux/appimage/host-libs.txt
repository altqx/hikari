# Libraries that always come from the host and are never bundled, in any
# HikariSub package of either codebase (the tar.gz, deb, rpm and AUR trees and
# the AppImage). One shell glob per line, matched against the file name of a
# library (its soname). Lines starting with # and blank lines are ignored.
#
# This file has the same bytes on the legacy (main) and Qt (qt) branches.
# The packaging scripts read it; a CI check fails when a package tree holds a
# file that matches it. Anything one of these libraries needs is host-side too
# (the closure rule): the collectors resolve their dependencies in the build
# container and leave those out of the bundle as well.

# The C++ runtime: a bundled older copy would win over the host's and break
# host plugins that need a newer one.
