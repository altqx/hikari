1 The Template editor, docked as a tab beside the Line editor, with the preview on the video.
Opened from View › Panels › Template editor (and by KP1's Karaoke preset later). It edits the Document's template and code Lines like any other edit (the Grid shows the new text, Ctrl+Z takes it back). Each edit re-runs the templater on the current Line only, and the video draws that result in place of the Line's generated Lines; no generated Line is written until Apply. The Grid marks a template Line changed since the last Apply (●).
