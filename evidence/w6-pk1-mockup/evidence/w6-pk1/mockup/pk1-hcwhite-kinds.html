PK1 popup kit: the four kinds (High contrast white)

WindowDG1’s frame: a top-level window, centred on its opener the first time, then where it was left; Esc closes it. Anything with more than three fields, or anything opened from a menu or hotkey that is not a small form.
Message boxA question or notice that needs an answer: a window on DG1’s frame, modal to its parent window only, fixed size. Title: the command it comes from. A severity icon, one main line, an optional detail, buttons named for what they do, in the platform’s order.
PopoverAnchored to the control that opened it, below it (above where there is no room). The colour popover’s frame. A press outside or the anchor again closes it and keeps the change; Esc closes it and puts the value before back. In a window of its own when the host window is too small for it.
NoticeA toast or an inline bar (over the main window, next page). Never a message box with only OK.
Small formsThree fields or fewer: a popover from an on-screen control, a compact window from a menu or hotkey (the same content).
