2Runs inside the Line: write the sentence your way, then select a word and press its run key.
Original She {\i1}really {\i0\b1}hates{\b0} the rain. (the text0{\i1}text1{\i0\b1}text2{\b0}text3 shape). The Original text shows each run in its formatting with a number; the Translated field is plain text and a Runs strip lists what is still to place (hollow). Select “hasst”, press Alt+2 (or click the chip): it turns bold and the chip fills. Runs go in any order — here 2 before 1, as German needs. “Place next run” (one key, like memoQ F9 / Phrase F8) takes the lowest unplaced run; Ctrl+B / Ctrl+I / Ctrl+U on a selection place the matching run when the original has one. Pressing a run key again on placed text removes the run; Ctrl+Z undoes as usual.

3A suggestion, never a silent guess.
When a run’s text appears unchanged in the translation (names, numbers, titles), it is offered with a dotted underline; Tab accepts, Esc dismisses, typing on ignores it. Only this exact-match signal at first: no word aligner or online translation service (published tag-placement accuracy is 72–95 %).

4A run left unplaced never blocks you; the Grid marks the Line.
Committing with runs unplaced writes no empty tag pairs. The Line gets a “runs not placed” mark (a column the Grid can show and filter on), separate from Not confirmed. Brace comments, \N breaks, karaoke (\k) and drawings (\p) are not carried: you break lines for your language; karaoke and drawing Lines get the leading tags only.

6The translation follows later edits to the original’s tags.
Dragging \pos on video or changing \fad in the original updates the translation’s carried tags in the same undo step — unless they were edited by hand there, then the Line is marked “tags differ from original” and nothing is overwritten. Placed runs follow value changes (a new colour); a run added to the original shows as a new chip.
