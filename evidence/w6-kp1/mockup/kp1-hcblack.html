2Choosing Karaoke turns Karaoke mode on; leaving it puts back the mode it replaced.
Karaoke is the fifth preset in View > Layout and the layout switcher. Choosing it, or a saved layout made from it, switches the audio panel to Karaoke mode silently (no question, unlike Translation: nothing in the file changes). Choosing another arrangement afterwards puts Line mode back, but only if Karaoke was the one that turned Karaoke mode on and the user hasn't switched it since. The Line | Karaoke switch keeps working in every layout. Showing a tab, opening a file, a Session's arrangement and Reset this layout switch nothing (TM1's rule).

3Generated Lines fold into one row per run, and unfold with a click.
Generated Lines are those the templater wrote (Effect fx) and Kara Effector's (Effector [fx]). Each run of them shows as one row with the Line numbers it covers, its time span, its Styles and how many Lines it holds. A click on the row's arrow, or → with the row current, unfolds it; ← or the arrow folds it again. Choosing Karaoke folds every run; the Grid's ⋯ menu has Fold generated Lines in any layout. Folding only hides rows: the Lines stay in the file, play on the video and are found by Find, which unfolds the run it lands in.

6Questions for the owner, and notes
  1. Arrangement: Video and the Template editor on top, Audio across the full width, a short Grid below (A, recommended), or Editing's shape with Audio above the Template editor (B).
  2. The Line editor: a tab behind the Template editor, where KE2 puts the Template editor today (recommended), or a panel of its own below the Template editor, which then loses its preview table.
  3. Which Lines fold: Effect fx (the templater) and Effector [fx] (the bundled Kara Effector) (recommended), or fx only.
  4. A folded row: one row per run of generated Lines, its arrow or →/← to unfold and fold; clicking the row selects every Line in the run, so Delete, Copy and Shift times act on the whole run (recommended). The alternative is a row that can't be selected, only unfolded.
  5. Leaving Karaoke: puts back Line mode and unfolds the runs, but only what Karaoke itself changed: a mode or fold the user changed while in Karaoke stays as they set it (recommended). The alternative is to keep Karaoke mode and the folds after leaving, as Translation keeps its mode.

No new panel and no new ids. Karaoke arranges panels that exist once KE2 (#284) merges: Video, Audio, Template editor, Line editor, Grid. No hotkey or panel registry number is needed.

Closed in Karaoke: Styles, Search, Timing, History, Original text and the Log, each in its usual place; View > Panels opens them. In Translation mode the Original text takes its place above the Line editor (TM1).

Built like Typesetting: the arrangement is built the first time Karaoke is shown in a session (TP1's buildsArrangement). A tab, Session, file or saved layout holding a Karaoke arrangement keeps its own panels until Karaoke is chosen again or the layout is reset.

Without audio: the Audio panel shows its Open audio placeholder and the mode is set, ready for the audio.

Docs and tests: docs/qt/ux/workspaces.md gets the Karaoke row and section. Tests cover the panel set on a fresh profile and after Reset, the mode switched on and put back, the fold and unfold, and Find unfolding.
