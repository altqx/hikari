Select lines: a modeless window of its own (it can leave the main window). Short labels instead of five group boxes: field, case and regex; which field; Dialogue / Comments; the selection; then an action (the seven legacy actions in a list). The styles button opens PK1’s Choose styles popover. Select stays open and posts the count as a toast (legacy asked “Close / OK”). Enter in the field selects.

History: a resizable window, modeless, so the grid stays usable. The current step is bold and marked; undone steps are muted. Go to step (Enter, or a double-click) jumps there and stays open; Close or Esc closes. Legacy’s Set / OK / Cancel and the count in the title go.

Translation matching options
Original: the text with the right timing. The pasted dialogue is matched to it, and it is deleted later.
Translation: the text pasted in, moved line by line until each one sits beside its original.
