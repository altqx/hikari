Search matches the name and the path as you type (every word, as legacy’s “All words”). Saved filters by date with the shared date filter: Any time, Today, Last 7 days, Last 30 days, Before a date…. Version picks one of the bundle’s autosaves, the latest first. Open copy opens it as a new unsaved copy and closes the window. The bin deletes the bundle at once; the previous version’s are read only, so theirs is disabled.
