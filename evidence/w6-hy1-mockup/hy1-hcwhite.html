The change option is a four-way switch. The choices that refine it sit in the list beside it: where Set puts the tag, the two ways Multiply counts lines, the four gradients. Every one of legacy's eight options and three placings is there.
The values say what they do. Set shows Value; Add shows By; Multiply shows Start and Per line; a gradient shows From and To. Legacy left these in a slider's distance from where the drag began.
Changes N lines sits where VT1's target slot was. The picked Lines are outlined and numbered on the video before you apply, in the order Multiply and line gradients count them. With none picked it reads Changes the active line.
With several Lines, the tag always goes at the start of each Line's text, so the placing list greys out.
