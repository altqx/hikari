2Choosing Translation on a file without TLMode asks once.
From View > Layout or the layout switcher. Window-modal, Turn on is the default (Enter). Turn on: one undo step (“Turning on translator mode”) and the Original text panel appears. Not now: the tab keeps the arrangement without the mode and the question isn’t asked again in this tab. SRT and other line formats get the arrangement only.

3Subtitles › Translation mode: bindable; turning it off asks as today.
A checked item with its own hotkey (none by default; Shift+click maps it). Checking it turns the mode on at once; unchecking asks today’s question, No by default. Turning the mode off closes the Original text panel; the tab keeps its arrangement.

4Another preset keeps the mode on: here Editing, with Original text above the Line editor.
